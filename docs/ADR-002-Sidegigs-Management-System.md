## ADR-002: Frontend Technology Choice (Twig + HTMX)

**Status:** Decided  
**Date:** 2026-06-07

**Decision**: Use Twig + HTMX + Alpine.js + TailwindCSS instead of React SPA for the initial version.

**Rationale**:
- Matches user's comfort level
- Faster iteration
- Smaller bundle, simpler deployment
- Sufficient for Kanban + forms

Future migration path to React remains open.
